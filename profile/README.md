# WiMilk

**Pecuária leiteira de precisão com visão computacional.**

A WiMilk é uma startup agtech de Goiás que monitora o rebanho 24 horas por dia com
inteligência artificial e visão computacional. O objetivo é pré-detectar sinais de
mastite bovina e alertar o pecuarista no celular.

## O que estamos construindo

- **Captura e dados:** imagens de câmeras na fazenda, enviadas à nuvem e anotadas para
  formar um dataset próprio.
- **Modelos de visão computacional:** detecção de bovinos e de postura, usada como base
  para indicadores de rebanho.
- **Relatórios para o produtor:** resumos por lote, pensados para a rotina da fazenda.

> O produto está em desenvolvimento. Os indicadores ainda não substituem avaliação
> veterinária.
